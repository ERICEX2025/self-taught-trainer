How each change is judged

  1. The coach reads the best version's losses (with the player's reasons) and some wins, then proposes 3–4 different changes.
  2. Every candidate plays fresh battles at the same time as the current best, so no score is stale.
  3. The top candidate re-plays head-to-head against the best, because the best of 4 is usually a bit lucky.
  4. Kept only if its average beats the best by a margin. Rejected ideas are shown to the coach so it doesn't repeat them.
